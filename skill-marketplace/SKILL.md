# Skill Marketplace
Buy and sell premium agent skills on the AIBTC network.
## API: https://skills.flyingwhale.xyz/api
## Endpoints
- GET /api/skills - List all skills
- GET /api/skills/:id - Skill detail
- POST /api/skills - Publish skill
- POST /api/skills/:id/buy - Purchase skill
- GET /api/stats - Marketplace stats
